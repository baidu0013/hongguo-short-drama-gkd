# 红果短剧广告规则

供 [GKD](https://github.com/gkd-kit/gkd) 使用的个人订阅，适配应用包名 `com.phoenix.read`。本仓库发布的是完整订阅文件 `gkd.json5`，不是需要手动嵌套的单个应用规则片段。

## 订阅

GitHub Raw 订阅链接：

`https://raw.githubusercontent.com/baidu0013/hongguo-short-drama-gkd/main/gkd.json5`

在 GKD 的订阅管理中添加该文件的原始内容链接，然后确认红果应用下需要的规则组已经启用。请不要将 GitHub 文件浏览页面地址当成订阅地址。

已有红果同类上滑规则时，先停用重复规则，避免不同订阅同时操作页面。刷新订阅不会代替检查用户先前手动关闭的规则组。

## 规则范围

| 组 key | 功能 |
| --- | --- |
| 0 | 开屏广告：匹配跳过文字或指定开屏按钮 |
| 1 | 阅读页底部卡片广告：关闭卡片并处理后续关闭入口 |
| 2 | 阅读页视频广告：匹配可关闭提示且没有指定读秒提示时横向滑动 |
| 4 | 青少年模式提示：保留原有提示处理规则，按需启用 |
| 5 | 短剧广告：可见上滑提示出现后延迟上滑，提示仍在时持续重试 |

短剧规则同时匹配以下无障碍文字节点，且要求 `visibleToUser=true`：

```json5
'[text="上滑继续观看短剧" || text="上滑继续看短剧"][visibleToUser=true]'
```

计时参数：

```json5
actionDelay: 1000,
actionCd: 1000,
```

首次匹配后约 1 秒尝试上滑；动作触发后有 1 秒冷却，再次匹配还需等待 1 秒，因此提示持续可见时通常约每 2 秒再尝试一次。这里不是固定的 2 秒定时器，也不限制只重试一次。调度、节点变化和服务状态会影响时间；未完成的延迟可能被后续匹配继承，不能保证每条新广告都重新完整等待 1 秒。

读秒与不读秒共用文字条件，不读取或猜测倒计时。只有画面上能看到文字而无障碍树没有对应可见节点时，不会触发。提示消失后不再满足该文字条件，但动作触发记录并不等于广告确实被划走。

- 这是个人适配规则，不是红果或 GKD 官方订阅，不能保证所有广告、应用版本与设备均适用。
- 仅完成离线文件解析与结构校验，不代表已经通过真机覆盖测试。页面切换、节点可见性变化或应用改版仍可能造成漏滑或误操作。
- 青少年模式组保留了原有较宽的“我知道了 / 知道了”匹配，可能影响其他同文案提示；不需要时可单独停用该组。本次发布未修改其行为。
- 发生误滑时先停用对应组；反馈请附应用版本、GKD 版本、组 key、动作记录时间，以及问题页面的 GKD 快照。上传前检查并遮盖个人信息。
- GitHub Raw 在部分网络不可达；请先确认设备能够打开订阅原始链接。这不是手机实测成功的保证。

## 更新与验证

维护时保持顶层订阅 `id` 不变；每次发布新规则递增整数 `version`，否则客户端不会把相同版本视作更新。未指定 `updateUrl` 时，GKD 使用添加订阅时填写的链接。

需要 PowerShell 7、Node.js 和 npm；验证脚本会通过 `npx` 使用固定版本 `json5@2.2.3` 解析文件：

```powershell
pwsh -File ./verify.ps1
```

需要与发布前应用规则进行逐字段对比时：

```powershell
pwsh -File ./verify.ps1 -SourcePath ../hongguo-red-fruit-retry-20260907.json5
```

检查覆盖 JSON5 解析、订阅基础结构、应用及规则组标识、短剧文案与时间参数；可选原文件比对要求 `apps[0]` 与原应用规则完全一致。验证不执行无障碍查询，不模拟手机手势，也不代表 GKD 全字段或选择器引擎验收。
